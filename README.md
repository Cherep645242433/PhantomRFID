# 👻 PhantomRFID

**Цифровая связка ключей от Phantom Road Studio**

PhantomRFID — это надежное и удобное приложение для хранения цифровых ключей от домофонов. Создайте личную базу UID-кодов, чтобы вы больше никогда не забыли нужный ключ.

---

## 🚀 Основные возможности
*   **Удобное добавление:** Сохраняйте название (Дом, Гараж, Офис) и UID-код в один клик.
*   **Управление:** Легко находите нужный ключ или удаляйте устаревшие записи.
*   **Безопасность:** Все данные хранятся локально на вашем компьютере.
*   **Стильный интерфейс:** Темная тема в фирменных цветах студии.
