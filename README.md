# PhantomRFID
Цифровая связка ключей от Phantom Road Studio
ОПИСАНИЕ ПРОГРАММЫ
PhantomRFID — это надежное и удобное приложение для хранения цифровых ключей от домофонов. Созданная студией Phantom Road Studio, программа позволяет создать личную базу UID-кодов, чтобы вы больше никогда не забыли нужный ключ.

Основные возможности:
- Удобное добавление ключей (название + UID).
- Поиск и редактирование записей.
- Надежное хранение данных на вашем компьютере.
- Стильный интерфейс в фирменных цветах.

СИСТЕМНЫЕ ТРЕБОВАНИЯ
- Операционная система: Windows 7 / 8 / 10 / 11 (32-bit или 64-bit).
- Платформа: .NET Framework 4.0 или выше.
- Оперативная память: Минимум 64 МБ.
- Место на диске: 10 МБ свободного пространства.
- Права: Права администратора (только для установки).
